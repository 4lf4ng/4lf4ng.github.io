# 4LF4 Website

Responsive, nine-page website for 4LF4 Limited. Version B is the canonical design.

## Pages

- `index.html` — Homepage
- `about.html` — About 4LF4
- `ecosystem.html` — 4LF4 ecosystem
- `business.html` — ALFA Business
- `academy.html` — ALFA Academy
- `projects.html` — Projects
- `events.html` — Events
- `careers.html` — Careers
- `contact.html` — Contact

## Shared files

- `styles.css` — Shared responsive design system and page styling
- `script.js` — Theme preference, mobile navigation and automatic footer year

## Brand assets

- `assets/logos/4lf4-icon.svg` — Official 4LF4 symbol
- `assets/logos/4lf4-wordmark.svg` — Official 4LF4 wordmark

The shared navigation uses the 4LF4 symbol and wordmark text consistently. Division-specific visual treatments remain within the Business and Academy pages.

## Local preview

Open `index.html` in a browser. No build tools or installation are required.

## GitHub Pages deployment

1. Upload the contents of this folder to the repository root.
2. Commit the changes to the `main` branch.
3. In repository Settings → Pages, choose **Deploy from a branch**.
4. Select `main` and the root folder, then save.

Website: https://4lf4ng.github.io

## Before production

- Verify the public contact email and any division-specific contact details.
- Add approved social media links if required.
- Add privacy and legal pages if required.
- Test the deployed pages on desktop and mobile.
